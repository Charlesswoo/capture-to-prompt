CaptureToPrompt

화면 캡처 한 번으로 AI 이미지 생성 프롬프트를 만드는 macOS 앱

macOS 26+ 한 · 영 · 일 프롬프트 API 키 없이 사용 가능 사내 전용
목차 1. 소개 2. 설치 3. 설정 4. 사용법 5. 문제 해결

1소개와 목적

CaptureToPrompt는 마음에 드는 이미지를 발견했을 때, 캡처 한 번으로 그 이미지를 재현할 수 있는 AI 이미지 생성 프롬프트를 뽑아주는 데스크톱 앱입니다. PromptCard 크롬 확장의 데스크톱 대체품으로, 브라우저 밖 어디서든(디자인 툴, 문서, 영상 프레임 등) 동작합니다.

무엇을 해주나

  • 창/영역/클립보드/파일/드래그로 이미지를 가져오면 AI가 분석해 한국어·영어·일본어 프롬프트 + JSON을 생성
  • 주제·스타일·구성·조명·색감·분위기·매체·태그로 나눈 구조 분석(메타) 제공
  • 생성된 영문 프롬프트로 바로 이미지 생성까지 이어서 실행 (결과 비교 가능)
  • 분석 결과는 히스토리에 자동 저장, 프롬프트는 앱 안에서 직접 수정 가능

핵심 특징

  • API 키가 없어도 됩니다 — Claude 구독(Claude Code) 또는 ChatGPT 구독(Codex) 로그인만 있으면 분석·이미지 생성 모두 가능
  • 어느 앱에서든 ⌥⇧C 전역 단축키로 마우스 아래 창을 즉시 캡처·분석
  • 시스템 언어에 따라 한국어/영어 UI 자동 전환

2설치

요구 사항

  • macOS 26 이상 (Apple Silicon)
  • 아래 넷 중 하나만 있으면 됩니다:
    • Claude 구독 + Claude Code CLI
    • ChatGPT 구독 + Codex CLI (이미지 생성까지 기본 지원 — 3장 참고)
    • Anthropic API 키

설치 순서

  1. 전달받은 CaptureToPrompt.zip의 압축을 풀고 CaptureToPrompt.app을 응용 프로그램(/Applications) 폴더로 이동합니다. (Spotlight·Alfred 검색에 필요)
  2. 첫 실행은 앱을 우클릭 → 열기 → 열기로 실행합니다. (사내 배포용이라 Apple 공증이 없어 더블클릭으로는 처음에 열리지 않습니다)
  3. 첫 캡처 시 화면 기록 권한을 요청하면 시스템 설정 → 개인정보 보호 및 보안 → 화면 및 시스템 오디오 녹음에서 허용 후 앱을 다시 실행합니다.

소스에서 빌드 (개발자)

git clone 후 프로젝트 루트에서:

./scripts/make_app.sh --install — 빌드 → 서명 → /Applications 설치까지 한 번에

검증은 swift build && swift test.

3설정 (메뉴 막대 CaptureToPrompt → 설정, ⌘,)

분석 백엔드 — 이미지를 분석할 AI 선택

백엔드필요한 것설명
Claude Code CLI기본 claude CLI + Claude 구독 로그인 키 불필요. 가장 정확한 분석. CLI 특성상 30~60초 소요
Codex CLI (ChatGPT) codex CLI + ChatGPT 로그인 키 불필요. ChatGPT 구독으로 분석 (아래 설정법 참고)
Anthropic API 키 API 키 키를 입력하거나 ANTHROPIC_API_KEY 환경변수 사용. 모델 선택 가능

Claude CLI를 설치했는데 감지가 안 되면 "claude 경로" 칸에 터미널에서 which claude로 나온 경로를 입력하세요.

ChatGPT로 사용하기 (Codex CLI)

Claude 구독이 없고 ChatGPT 구독(Plus/Pro/팀)이 있다면 Codex CLI로 분석과 이미지 생성을 모두 쓸 수 있습니다:

  1. 터미널에서 설치: brew install codex (또는 npm i -g @openai/codex)
  2. 로그인: codex login → 브라우저에서 ChatGPT 계정으로 로그인
  3. 앱 설정에서 백엔드를 Codex CLI (키 불필요)로 선택 — 위 스크린샷처럼 "codex CLI 감지됨"이 초록색으로 나오면 준비 완료
  4. 이미지 생성 엔진은 기본값이 이미 Codex CLI라 따로 만질 것이 없습니다

이미지 생성 엔진

엔진필요한 것설명
Codex CLI (ChatGPT)기본 codex CLI + ChatGPT 로그인 키 불필요. ChatGPT 구독으로 생성 (약 1분)
OpenAI 호환 API API 키 Base URL·모델 지정 가능. 키를 비우면 OPENAI_API_KEY 환경변수 사용

동작 옵션

  • 캡처 후 자동 분석 (기본 꺼짐) — 꺼져 있으면 캡처한 이미지를 먼저 확인한 뒤 분석 시작 버튼(⌘↩)으로 분석합니다. 켜면 캡처 즉시 분석. 파일 열기·클립보드는 항상 바로 분석합니다.
  • 전역 캡처 단축키 — 기본 ⌥⇧C, 다른 조합으로 변경 가능
  • 배경 투명도 — 창의 유리 효과 강도 조절

4사용법

① 이미지 가져오기

방법단축키설명
창 캡처⌘1 / 전역 ⌥⇧C마우스 커서 아래 창을 자동 인식해 캡처. 전역 단축키는 어느 앱에서든 동작
창 선택⌘2열린 창들을 그리드로 보고 클릭해 선택 (가려진 창도 캡처 가능)
영역 캡처⌘3화면 영역을 드래그로 선택
클립보드⌘⇧V복사해둔 이미지 분석
파일 열기⌘O이미지 파일 선택 (창에 드래그해도 동일)

② 결과 활용

  • 언어 탭 — 한국어 / English / 日本語 / JSON({}) 전환, ⌘⇧C로 현재 탭 복사
  • 프롬프트 수정 — 연필 버튼을 누르면 패널 전체가 편집기로 전환. 저장(⌘S)하면 이미지 생성과 히스토리에도 수정본이 반영, 취소는 Esc
  • 메타 › — 클릭하면 주제·스타일·조명 등 구조 분석이 펼쳐집니다. 태그는 클릭으로 개별 복사

③ 이미지 생성

  • 결과 패널 하단의 이미지 생성 버튼 — 영문 프롬프트로 이미지를 만듭니다
  • 완성되면 왼쪽 패널이 원본 | 생성 전환 보기로 바뀌어 비교할 수 있습니다
  • 하단 바의 복사 / 저장…으로 생성 이미지를 활용, 다시 생성으로 재시도

④ 히스토리

  • 분석할 때마다 왼쪽 사이드바에 자동 저장 — 클릭하면 언제든 다시 열람
  • 우클릭으로 프롬프트 복사·삭제

5문제 해결

"API 오류 (127): env: node: No such file or directory"
npm으로 설치한 claude를 GUI 앱이 못 찾는 경우입니다. 최신 버전은 자동으로 경로를 찾지만, 그래도 실패하면 설정 → "claude 경로"에 which claude 결과를 입력하세요.
"claude CLI를 찾을 수 없습니다"
Claude Code가 설치되지 않은 PC라면 설정에서 다른 백엔드(Codex CLI / Anthropic API 키)를 선택하세요.
"codex CLI를 찾을 수 없습니다"
brew install codex 설치 후 codex login으로 ChatGPT 계정 로그인이 되어 있는지 확인하세요.
캡처가 검게 나오거나 실패
시스템 설정 → 개인정보 보호 및 보안 → 화면 및 시스템 오디오 녹음에서 CaptureToPrompt를 허용한 뒤 앱을 재실행하세요.
Spotlight / Alfred에서 앱이 검색되지 않음
앱이 /Applications에 있어야 합니다. 다운로드 폴더 등에서 실행 중이면 옮겨주세요.
분석이 오래 걸림
CLI 백엔드는 보통 30~60초가 정상입니다. 더 빠른 응답이 필요하면 Anthropic API 키 백엔드를 사용하세요.
